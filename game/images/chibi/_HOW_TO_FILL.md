# Chibi flat images — drop your PNGs here

Engine: ../../chibi_flat.rpy   (registrar; leave the layeredimage in ch/gen/images.rpy alone)

Put ONE flat PNG per activity in THIS folder, named exactly <activity>.png.
Each is the whole little MC pose for that activity. Transparent background is fine.

Optional:
  bg.png     -> shared backdrop drawn behind EVERY pose (leave out to bake bg into each pose)
  idle.png   -> generic fallback shown for any activity whose own PNG is missing

Missing files never crash — an unfilled activity just shows blank until you add it.
